# ميزان — تقييم البنوك السعودية

موقع عربي ثابت مناسب لـ GitHub Pages. يعرض عشر بنوك، وربح السهم السنوي من الملف المرفق، وأربع طرق للتقييم، ثم **المتوسط الحسابي المتساوي للنتائج الأربع**. يمكن اختيار ربح السهم الأساسي أو المخفف. الأسعار والأساسيات المحدثة تُجلب في GitHub Actions باستخدام مفتاح محفوظ في أسرار المستودع، ثم تُنشر لقطة الصفحة والبيانات. جدولة GitHub قد تتأخر؛ الموقع يوضح وقت آخر سعر وحالة تأخير المزود، ولا يصف اللقطة بأنها بث لحظي.

## الحالة عند فتح المشروع

- بدون مفتاح مزود البيانات: يظهر مثال توضيحي للراجحي بأرقام سعر ومكررات **افتراضية وموسومة بوضوح**. بقية البنوك تعرض تاريخ الأرباح، ويمكن تجربة التقييم من لوحة الإدخال اليدوي.
- مع مفتاح وخطة مناسبة: تستخدم الصفحة السعر وربح السهم والقيمة الدفترية من [واجهة سهمك](https://www.sahmk.sa/en/developers/docs/getting-started). في الباقة المجانية تُجلب أسعار الأسهم المفردة فقط، ويبقى السعر العادل غير متاح لأن ربح السهم الحالي والتاريخ السعري اللازمين للطرق الأربع لا يتوفران فيها. حقل ربح السهم المخفف قد يكون خاليًا لدى المزود؛ تظهر عندها النتيجة غير متاحة.
- ربح السهم والقيمة الدفترية من ملف الإكسل تُستخدم للتاريخ أو في وضع الإدخال اليدوي. تاريخ القيمة الدفترية في الملف غير موضح؛ لذلك لا تُعامل على أنها قيمة محدثة تلقائيًا.

## الحساب

1. النمو: ربح السهم الحالي × المتوسط الحسابي لمعدلات نمو ربح السهم السنوية بين 2020 و2025، بوحدة النقاط المئوية (مثل 19.35 وليس 0.1935). إذا كانت إحدى سنوات الأساس صفرًا أو سالبة، لا يُحسب هذا التقدير.
2. القطاع: ربح السهم الحالي × **وسيط** مكررات البنوك النظيرة، مع استبعاد البنك المختار. مكرر كل نظير = سعره ÷ ربح سهمه على الأساس المختار.
3. جراهام: الجذر التربيعي لـ 22.5 × ربح السهم الحالي × القيمة الدفترية للسهم.
4. التاريخي: ربح السهم الحالي × متوسط مكررات السنوات المالية الست 2020–2025. مكرر السنة = سعر الإغلاق المعدل لنهاية السنة ÷ ربح السهم السنوي في الملف. يجب توافر السنوات الست كلها.

السعر العادل = مجموع التقديرات الأربعة ÷ 4، باستخدام الدقة الكاملة قبل تقريب العرض. عند غياب أي تقدير، يُعرض «—» للسعر العادل بدل متوسط عدد أقل من الطرق. الفارق عن السعر = (السعر العادل ÷ سعر السهم − 1) × 100. طريقة النمو قد تعطي نتيجة كبيرة إذا قفز ربح السهم من أساس منخفض؛ تعرض الصفحة تنبيهًا ولا تغير المعادلة من تلقاء نفسها.

## مصدر البيانات وحدوده

ملف `site/data/banks.json` مستخرج من `البنوك.xlsx` الذي زوّدنا به المستخدم، ويحتفظ باسم الورقة وخلايا ربح السهم وبصمة الملف. لم تُستخدم صيغ أسعار GOOGLEFINANCE ذات القيم الاحتياطية الثابتة في الملف كأسعار حديثة. بعض قيم ربح السهم المخفف في الملف أعلى من الأساسي؛ وُسمت هذه الحالات للمراجعة مع إفصاحات البنوك.

المزود المقترح هو [سهمك](https://www.sahmk.sa/en/developers/pricing): الأسعار المتأخرة متاحة في الخطط الأقل، أما حقول ربح السهم والمكرر والقيمة الدفترية والتاريخ السعري فتحتاج الباقة المبتدئة أو أعلى بحسب توثيقه الحالي. المفتاح لا يظهر في ملفات الصفحة. قبل إتاحة الصفحة للعامة، راجع [سياسة عرض البيانات ونسبتها للمزود](https://www.sahmk.sa/en/legal/commercial-usage) لنوع الاشتراك والاستخدام المطلوب. الأسعار التاريخية المعدلة وربح السهم من مصدرين مختلفين؛ يجب مراجعة أثر التجزئة وزيادات رأس المال قبل الاعتماد على المكرر التاريخي.

## التشغيل محليًا

لتجربة مفتاحك على جهازك، شغّل الأمر التالي من داخل مجلد المشروع. سيطلب المفتاح دون إظهاره أثناء الكتابة، ويكتب بيانات السوق فقط في ملف محلي مستبعد من المستودع:

```bash
python3 scripts/refresh_market.py --prompt
```

تحقق من أن ملخص الأمر يذكر البنوك المحمّلة وعدد الملاحظات. إذا ظهرت أخطاء صلاحية أو خطة، راجع باقتك في سهمك. بعد ذلك شغّل الصفحة:

```bash
python3 -m http.server 8000 --directory site
```

افتح `http://localhost:8000`. لا يحتاج العرض الأساسي إلى بناء أو تنزيل مكتبات. للاختبارات:

```bash
node --test tests/valuation.test.mjs
python3 -m unittest discover -s tests
```

لإعادة استخراج تاريخ البنوك من نسخة مصححة من الملف:

```bash
python3 -m pip install -r requirements.txt
python3 scripts/extract_banks.py /path/to/البنوك.xlsx site/data/banks.json
```

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى مستودع GitHub على الفرع `main`.
2. من إعدادات المستودع، فعّل Pages واجعل المصدر `GitHub Actions`.
3. أضف مفتاحك بنفسك في `Settings → Secrets and variables → Actions` باسم `SAHMK_API_KEY`. تحتاج خطة تتيح أساسيات الشركات والتاريخ السعري، وإلا ستظهر بعض طرق التقييم غير متاحة. لا تضع المفتاح في الصفحة أو المستودع أو هذه المحادثة.
4. شغّل مهمة `Publish bank valuation site` يدويًا أول مرة، وتحقق من ملف سجل المهمة ومن ظهور السعر وتاريخه على الموقع. التحديثات المجدولة تستهدف لقطة كل ساعة خلال ساعات التداول حتى لا تتجاوز طلبات الأسعار المفردة حد الباقة المجانية، مع احتمال تأخير التنفيذ من GitHub.

إذا تعذر وصول المزود إلى بعض البيانات، تعرض الصفحة القيم الناقصة بوضوح. لا يعني نجاح نشر Pages أن ربط بيانات السوق نجح؛ تحقّق من نتيجة مهمة التحديث ومن الصفحة المنشورة.

## الملفات الرئيسية

- `site/index.html`: الواجهة المتجاوبة.
- `site/app.mjs` و`site/valuation.mjs`: العرض والحسابات.
- `site/data/banks.json`: بيانات الملف التاريخية.
- `scripts/refresh_market.py`: إنشاء لقطة السوق بالمفتاح السري.
- `.github/workflows/pages.yml`: تحديث اللقطة ونشرها.
