# ميزان — تقييم البنوك السعودية

[افتح الموقع المنشور](https://portalnode.github.io/mizan-saudi-banks/)

صفحة عربية للبنوك السعودية العشرة. سعر السهم يأتي آليًا من سهمك عبر لقطة تنشرها GitHub Actions، والبيانات التي يُدخلها المستخدم لكل بنك هي **ربح السهم الأساسي، ربح السهم المخفف، والقيمة الدفترية للسهم** فقط. تُحفظ هذه المدخلات في متصفح المستخدم نفسه تحت المفتاح `mizan-current-inputs-v2`. يبقى المفتاح كما هو عند تحديث الصفحة، ولا تُمحى القيم المدخلة. اختيارات طرق التقييم تُحفظ لكل بنك في مفتاح مستقل. لا يُنشر مفتاح سهمك أو مدخلات المستخدم في ملفات الموقع.

تعرض قائمة البنوك السعر العادل والفارق عن سعر السوق لكل بنك مباشرة، وفق أساس ربح السهم المختار ومدخلات البنك واختيارات طرقه المحفوظة. تظهر شرطة عندما لا تكتمل بيانات الطرق المختارة.

## الحساب

- **المكرر الحالي:** سعر سهمك ÷ ربح السهم المدخل، وفق خيار الأساسي أو المخفف. يظهر في لوحة المدخلات ولا يحتاج إلى كتابة.
- **مكرر القطاع:** وسيط المكررات الحالية للبنوك النظيرة التي أُدخل ربح سهمها على الأساس المختار؛ البنك المحدد مستبعد. تعرض الصفحة عدد النظائر الداخلة. يلزم نظير واحد على الأقل.
- **متوسط المكرر التاريخي:** المتوسط الحسابي للمكررات الموجبة المتاحة من 2020–2025 الموجودة أصلًا في `البنوك.xlsx`؛ تعرض الصفحة عدد السنوات الداخلة. عمود المكرر في الملف لا يحدد هل استند إلى الربح الأساسي أم المخفف؛ تستخدم الصفحة القيمة المصدرية كما هي مع توضيح ذلك.
- **طريقة النمو:** ربح السهم الحالي × متوسط معدلات النمو السنوية المتاحة بين سنتين متتاليتين بربح سهم موجب في كلتيهما، من 2020 إلى 2025. تُستبعد فترة الانتقال من سنة الخسارة أو القيمة الناقصة، وتعرض الصفحة عدد الفترات المستخدمة. تُستخدم النسبة بوحدة النقاط المئوية كما في الصورة الأصلية؛ ولا تُحسب الطريقة إذا كان المتوسط غير موجب.
- **طريقة القطاع:** ربح السهم الحالي × مكرر القطاع.
- **رقم جراهام:** الجذر التربيعي لـ 22.5 × ربح السهم الحالي × القيمة الدفترية.
- **الطريقة التاريخية:** ربح السهم الحالي × متوسط المكرر التاريخي من الملف.

يمكن إدراج أو استبعاد كل طريقة لكل بنك. السعر العادل = مجموع نتائج الطرق المختارة ÷ عددها، قبل تقريب العرض. إذا نقصت بيانات طريقة **مختارة** فلا يظهر السعر العادل حتى تُستكمل بياناتها أو تُستبعد؛ الطرق المستبعدة لا تدخل الحساب. الفارق عن السعر = (نتيجة التقييم ÷ سعر السهم − 1) × 100، ويظهر للسعر العادل ولكل طريقة على حدة.

## المصدر والحدود

`site/data/banks.json` مستخرج من ملف المستخدم `البنوك.xlsx`، ويحفظ اسم الورقة والخلية لكل سنة وبصمة المصدر. خلية مكرر 2020 للبنك السعودي الأول فارغة لأن ربح السهم لذلك العام سالب؛ يحسب الموقع متوسط السنوات الخمس المتاحة، مع توضيح العدد. مكرر 2020 لبنك الجزيرة هو 331 كما ورد في الملف؛ لم يُعدّل ويظهر تنبيه لأثره المحتمل. لم يُستخدم سعر GOOGLEFINANCE الموجود في المصنف كسعر حديث، ولم تُستخدم قيمة دفترية من المصنف بدل مدخل المستخدم.

للبنك السعودي الأول، يُحسب متوسط النمو من الفترات الأربع الصالحة بين 2021 و2025؛ يُستبعد الانتقال من خسارة 2020 إلى ربح 2021 بدل اعتباره نموًا سنويًا عاديًا.

تُجلب الأسعار عبر طلبات سهمك الفردية، بفاصل سبع ثوانٍ بين الطلبات مراعاة لحد الباقة المجانية. المهمة المجدولة تستهدف لقطة كل ساعة خلال أوقات التداول، وقد يتأخر تنفيذ GitHub Actions. تعرض الصفحة وقت سعر المزود وحالة التأخير عند توافرهما. راجع [توثيق سهمك](https://www.sahmk.sa/en/developers/docs/getting-started) و[سياسة عرض البيانات](https://www.sahmk.sa/en/legal/commercial-usage).

## التشغيل والتحقق

```bash
python3 -m pip install -r requirements.txt
python3 scripts/extract_banks.py /path/to/البنوك.xlsx site/data/banks.json
python3 scripts/refresh_market.py --prompt
python3 -m http.server 8000 --directory site
```

تطلب أداة السوق المفتاح دون إظهاره أثناء الكتابة، وتكتب `site/data/market.json` المحلي المستبعد من Git. للاختبارات:

```bash
node --test tests/valuation.test.mjs
python3 -m unittest discover -s tests
```

في GitHub Pages، احفظ المفتاح في سر المستودع `SAHMK_API_KEY`. مهمة `.github/workflows/pages.yml` تولد لقطة السوق وتنشر الموقع. لا يكفي نجاح النشر للتحقق من وصول الأسعار؛ راجع حالة المهمة والسعر وتوقيته على الصفحة المنشورة.
